# AutoCalendar Web

App Next.js (drag-and-drop `.ods` → Google Calendar).

Instruções completas de **rodar local** e **deploy na Vercel** estão no [README da raiz](../README.md).

Resumo rápido:

```powershell
cd web
copy .env.example .env.local
# preencha GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, NEXTAUTH_SECRET, NEXTAUTH_URL
npm install
npm run dev
```
